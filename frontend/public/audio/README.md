# Wrapped soundtrack assets (Phase I)

Drop **MP3** files here. Vite serves them at `/audio/<filename>`.

## Required filenames

Use these exact names (add more by editing `frontend/src/config/wrappedAudioTracks.js`):

| File | Suggested vibe |
|------|----------------|
| `track-01.mp3` | Hip-hop / trap instrumental, mid tempo |
| `track-02.mp3` | Boom-bap or lo-fi beats |
| `track-03.mp3` | Electronic / jersey-club energy |
| `track-04.mp3` | Soul / R&B instrumental (warm) |
| `track-05.mp3` | Soul / R&B instrumental (warm) |
| `track-06.mp3` | Mainstream hip-hop instrumental |
| `track-07.mp3` | R&B / mood instrumental |

Each run of Wrapped **shuffles** this list on **Start Wrapped** and advances to the next track when one ends.

## Top 3 sources (royalty-free, basketball / rap-adjacent vibe)

Search terms: `hip hop instrumental`, `trap beat no vocals`, `sports hype`, `basketball`, `lo-fi beats`.

1. **[Pixabay Music](https://pixabay.com/music/search/hip%20hop/)** — Free for commercial use; strong hip-hop / electronic / cinematic filters; no account required for many downloads.
2. **[Mixkit Music](https://mixkit.co/free-stock-music/tag/hip-hop/)** — Free license for commercial use; good hip-hop and upbeat sport-style loops.
3. **[Uppbeat](https://uppbeat.io/browse/genre/hip-hop)** — Free tier with attribution (note artist in the table below); excellent modern beat-style instrumentals.

Also fine: [YouTube Audio Library](https://studio.youtube.com/) (filter Instrumental + Hip Hop).

## Export tips

- **Instrumental only** (no vocals) — keeps Wrapped readable.
- **30–90 seconds** loop-friendly; MP3 ~128 kbps keeps the bundle small.
- Normalize loudness across tracks so shuffle doesn’t jump volume.
